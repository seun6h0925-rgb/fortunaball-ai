## 1. 비회원 토큰 허용 길이가 DB 컬럼보다 김

- **발생 위치**: `backend/.../common/guest/GuestToken.java`, DB `number_issue.guest_token` (VARCHAR(64))
- **증상**: 토큰 형식 검사는 16~128자를 통과시키는데, DB 컬럼은 64자라 65자 이상 토큰으로 발급을 저장하면 길이 초과로 저장이 막힐 수 있었음
- **원인**: 토큰 검사 길이(128자)와 DB 컬럼 길이(64자)를 따로 정해서 서로 맞지 않았음
- **해결**: 검사 길이를 16~64자로 줄이고 테스트(65자는 거부)도 같이 수정 — 커밋 bf99310 (`fix/guest-token-length`), 병합 a64e3d7
- **재발 방지**: 입력 검사 길이는 해당 DB 컬럼 길이와 같이 정하고, 컬럼을 바꾸면 검사도 함께 확인
