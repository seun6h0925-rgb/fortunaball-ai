## 1. 홈 버튼 내용이 가운데로 안 보임

- **발생 위치**: `frontend/src/features/home/HeroCard.jsx`, `frontend/src/styles/home.css` (홈 상단 카드 "AI 애널리스트" · "AI 꿈풀이" 버튼)
- **증상**: "꿈풀이 번호"를 "AI 꿈풀이"로 바꾼 뒤 버튼 안의 아이콘과 글자 위치가 어색해 보임
- **원인**: 버튼의 가운데 정렬 규칙(`.btn`)은 이미 있었음. 아이콘과 글자의 세로 기준선·줄 높이 차이가 원인으로 추정됨 (화면에서 직접 확인하지는 못함)
- **해결**: 글자를 `<span>`으로 감싸고, 아이콘 크기 고정, 줄 높이·글자 위치 정리 (`.home-hero__sub .btn`)
- **재발 방지**: 버튼 문구를 바꾸면 두 버튼이 나란히 있는 화면에서 정렬까지 같이 확인

## 2. 공개 당첨 기록의 값이 비어 나옴

- **발생 위치**: 우리 서비스 당첨 기록 화면 (API-17 `/api/winning-records`)
- **증상**: "발급코드", "발급" 글자는 나오는데 코드·게스트·시각 값이 비어 있음
- **원인**: 프론트는 새 코드로 바뀌었는데 백엔드 서버가 변경 전 코드로 계속 실행 중이라 응답에 새 값이 없었음
- **해결**: IntelliJ에서 백엔드를 정지 후 다시 실행하고, 브라우저에서 Ctrl+F5 새로고침 → 값 표시 확인
- **재발 방지**: 백엔드 응답 구조를 바꾸는 작업은 파일 안내와 함께 "백엔드 재시작 → 새로고침" 순서를 먼저 안내

## 3. 하단 안내 문구와 문서가 예전 내용으로 남음

- **발생 위치**: `frontend/src/pages/WinnersPage.jsx`, `docs/` 명세서
- **증상**: 화면 하단에 "공개 기록에는 회차·등수·일치 개수만 보이고, 발급 번호와 개인정보는 없어요."가 그대로 있어 새 표시 내용(발급코드·게스트·발급 시각)과 맞지 않음. 명세서에도 같은 취지의 내용이 남아 있었음
- **원인**: 공개 범위를 바꿀 때 관련 화면 문구와 문서를 함께 찾아 고치지 않았음
- **해결**: 화면 문구를 "발급코드와 발급 시각은 그대로 공개해요. 게스트는 앞 4자리만 보이고, 번호는 발급코드로 조회할 수 있어요."로 수정. API·요구사항·기능·화면 명세서와 DB 설계서, 용어 사전에 같은 내용 반영
- **재발 방지**: 공개 범위·기준을 바꾸면 화면 문구, 문서, 코드 주석을 한꺼번에 검색해서 고침

## 4. 깊은 폴더 파일을 PC에서 가져오지 못함

- **발생 위치**: `backend/src/main/java/com/fortunaball/record/...` 등 7단계보다 깊은 폴더
- **증상**: 파일 가져오기에서 "too deeply nested" 오류
- **원인**: PC 파일 가져오기가 폴더 7단계까지만 지원함
- **해결**: GitHub에 올라간 사본을 받아 해당 4개 백엔드 파일을 수정하고 PC에 덮어씀 (관리자 화면 프론트는 GitHub 사본에 없어 PC 파일을 직접 가져와 수정)
- **남은 확인**: GitHub 사본이 PC 파일보다 오래됐을 수 있음. 이 4개 파일(`WinningRecordItem`, `WinningRecordService`, `AdminWinningRecordItem`, `AdminWinningRecordQueryService`)을 PC에서 따로 고친 적이 있으면 그 내용이 덮어써졌는지 확인 필요
- **재발 방지**: 깊은 폴더 파일은 GitHub 사본 기준으로 고치되, 덮어쓰기 전에 PC 쪽 변경 여부를 먼저 확인
