## 1. `cd frontend` 경로 오류

- **발생 위치**: PowerShell 터미널 (`frontend` 폴더)
- **증상**: 경로를 찾을 수 없다는 PowerShell 오류
- **원인**: 새 터미널이 이미 `frontend` 폴더 안에서 열려 있었는데 `cd frontend`를 안내함
- **해결**: 이미 프론트 폴더이므로 이동 없이 명령 실행
- **재발 방지**: 명령 앞에 터미널 위치를 먼저 확인

## 2. PowerShell 복사 실패

- **발생 위치**: PowerShell `Copy-Item` 명령 (`docs\_scratch\api`)
- **증상**: `Copy-Item`이 대상 경로를 찾지 못함
- **원인**: `docs\_scratch\api` 폴더가 아직 없었음
- **해결**: `New-Item -ItemType Directory -Force`로 폴더를 먼저 만든 뒤 복사
- **재발 방지**: 복사 명령 앞에 폴더 만들기를 항상 포함

## 3. `gradlew test --tests` 인자 사라짐

- **발생 위치**: PowerShell에서 `gradlew test --tests` 실행
- **증상**: 지정한 테스트만 실행되지 않음
- **원인**: 따옴표로 감싼 인자가 PowerShell을 거치며 사라짐
- **해결**: 전체 클래스 이름(`com.fortunaball.stat.dto.PatternStatResponseTest`)을 따옴표 없이 입력
- **재발 방지**: PowerShell에서는 테스트 이름을 따옴표 없이 입력

## 4. 모바일 패턴 화면 줄바꿈

- **발생 위치**: `frontend/src/styles/patterns.css`
- **증상**: 기간 칩과 패턴 이름이 좁은 화면에서 어긋나게 줄바꿈
- **원인**: 좁은 화면에서 칩 배치와 이름 영역의 폭이 맞지 않았음
- **해결**: 칩 배치와 이름 영역을 조정

## 5. PC 발급 내역 카드 넘침

- **발생 위치**: `frontend/src/styles/issues.css`
- **증상**: 발급코드와 삭제 버튼이 카드 박스 밖으로 나감
- **원인**: 코드와 버튼이 한 줄에 놓여 폭이 부족했음
- **해결**: 버튼 줄을 카드 아래 줄로 내림

## 6. "다시 뽑아줘" 문구 문제

- **발생 위치**: AI 애널리스트 화면 (`AnalystPage.jsx`)
- **증상**: 새로 고침 후 "다시 뽑아줘"를 누르면 입력창에 "3게임 뽑아줘"가 채워짐
- **원인**: 이전 생성 기록이 없을 때의 대체 문구가 고정 문구였음
- **해결**: 이전 생성 기록이 없으면 안내 말풍선을 보여 주도록 변경
- **재발 방지**: 대체 동작이 사용자의 말을 대신 만들지 않게 할 것

## 7. 루키 명당 목록이 비어 나옴

- **발생 위치**: `frontend/src/features/map/mapApi.js` (`fetchRookies`), 명당 지도 "루키 명당" 탭
- **증상**: 루키 명당 탭에 아무것도 나오지 않음
- **원인**: 화면이 한 번에 50곳을 요청했는데, 서버(API-66)는 1~10곳만 받음 → 400 "조회 개수는 1~10곳"
- **해결**: 요청 개수를 10곳으로 맞춤 (루키 명당은 10곳이면 충분하다고 확인)
- **재발 방지**: 목록 개수를 바꾸기 전에 서버가 허용하는 범위부터 확인

## 8. 루키 명당 안내 문구가 실제 기준과 다름

- **발생 위치**: `frontend/src/features/map/MapPanels.jsx` (루키 명당 안내 문구)
- **증상**: "새로 등록됐는데 벌써 당첨 기록이 있는 판매점"이라는 문구가 나오는데, 기간 기준이 없고 실제 규칙과 달랐음
- **원인**: 서버 판정 규칙(`RookieRule`)을 확인하지 않고 문구를 적음
- **해결**: 실제 규칙으로 정정 — "최근 1년 기준으로 당첨이 새로 많이 나온 판매점이에요. (1등 1회 이상 또는 2등 5회 이상)", 목록의 NEW 표시 삭제
- **재발 방지**: 화면 문구에 기준·숫자가 들어가면 서버 코드에서 실제 값을 확인한 뒤 적을 것

## 9. `jsqr` 가져오기 실패로 흰 화면

- **발생 위치**: `frontend/src/features/ticket/readQr.js`
- **증상**: Vite 화면에 "Failed to resolve import jsqr"가 나오고 페이지가 하얗게 나옴
- **원인**: QR 읽기용 `jsqr` 패키지를 코드에서 쓰는데 컴퓨터에 설치되지 않았음
- **해결**: `frontend` 폴더에서 `npm install jsqr` 실행 후 개발 서버 재시작
- **재발 방지**: 새 패키지를 쓰는 작업은 설치 명령을 같이 안내

## 10. lint 오류 - 상수 내보내기 위치, 안 쓰는 값

- **발생 위치**: `frontend/src/features/payout/PayoutPanels.jsx`
- **증상**: `npm run lint`에서 `react-refresh/only-export-components`(컴포넌트 파일에서 상수를 내보냄)와 `no-unused-vars`(안 쓰는 `tax`) 오류
- **원인**: 등수 목록(`RANKS`)을 컴포넌트 파일에서 함께 내보냈고, 쓰지 않는 값이 남아 있었음
- **해결**: 등수 목록을 `payoutRanks.js`로 옮기고 안 쓰는 값을 제거 → lint 통과
- **재발 방지**: 컴포넌트 파일에는 컴포넌트만 내보내고 상수·함수는 별도 파일에 둠

## 11. 수령 가이드 링크 위치·연결 대상 오류

- **발생 위치**: `frontend/src/features/payout/PayoutPanels.jsx` (계산 기준 카드), `frontend/src/pages/ClaimGuidePage.jsx`
- **증상**: 세금 계산 화면의 "계산 기준" 아래에 "당첨자 가이드" 링크와 큰 버튼이 어색하게 붙어 있었고, 링크가 가리키는 페이지 내용을 확인하지 않고 이름을 붙임
- **원인**: 링크 대상 페이지를 실제로 열어 보지 않고 문구를 정함
- **해결**: 동행복권 당첨자 안내 페이지(`https://www.dhlottery.co.kr/guide/wnrGuide`) 내용을 직접 확인한 뒤, "세율 출처" 줄을 삭제하고 링크를 수령 가이드 화면으로 이동. 계산 기준 안내 문구를 "동행복권에서 제시하는 세율을 적용한 계산이며, 자세한 내용은 당첨금 수령 가이드의 링크에서 확인" 취지로 재작성
- **재발 방지**: 외부 링크는 반드시 열어서 내용을 확인한 뒤 이름을 붙임

## 12. 명당 지도 화면 구성이 어색함

- **발생 위치**: `frontend/src/pages/MapPage.jsx`, `frontend/src/styles/map.css`
- **증상**: 지도 아래 파란 박스가 이상하고, 결과/TOP/루키를 고르던 선택 UI가 사라지고, 더보기가 아래로 길게 늘어남
- **원인**: 요청과 다르게 레이아웃을 바꾸었고, 더보기를 목록 아래로 펼치는 방식으로 만들었음
- **해결**: 파란 박스 제거, 세 탭을 한 카드로 되돌림, 더보기는 별도 창에서 50개씩 1 2 3 4 페이지로 이동 (TOP은 10개까지만 표시)
- **재발 방지**: 레이아웃을 바꿀 때는 이전 구성을 유지한 채 요청한 부분만 수정

## 13. 수정한 파일이 컴퓨터에 이전 버전으로 남음

- **발생 위치**: `frontend/src/App.jsx`, `frontend/src/styles/admin.css` 등 컴퓨터로 보낸 파일
- **증상**: 관리자 "회차 데이터" 메뉴가 새 화면이 아니라 "준비 중"으로 표시, 수정한 CSS도 반영되지 않음
- **원인**: 컴퓨터에 파일을 쓴 직후 이전 버전이 남아 있었음 (`App.jsx` 크기가 옛 값 4401바이트)
- **해결**: 파일을 다시 쓰고, 폴더의 파일 크기를 새 버전과 비교해서 반영 여부를 확인
- **재발 방지**: 파일을 보낸 뒤마다 컴퓨터 쪽 파일 크기를 확인하고, 확인 전에는 "반영됐다"고 말하지 않음

## 14. 발급 기록 상세에서 번호 공이 찌그러짐

- **발생 위치**: `frontend/src/styles/admin.css` (관리자 발급 기록 상세, 회차 데이터 목록)
- **증상**: 오른쪽 상세 칸의 번호 공이 길쭉하게 나옴
- **원인**: 칸이 좁아 공이 줄어들며 가로만 눌림
- **해결**: 공 크기를 고정(`flex: none`, `aspect-ratio: 1`)하고 칸이 모자라면 다음 줄로 넘김

## 15. 홈 "최근 상승 지역" 더보기 연결 오류

## 16. 화면이 계속 "불러오는 중"

- **발생 위치**: 프런트 개발 서버 (`npm run dev`, 5173)
- **증상**: 백엔드 서버를 다시 켜도 관리자 화면이 계속 불러오는 중
- **원인**: 백엔드가 아니라 프런트 개발 서버(Vite)가 멈춤. 브라우저 기록에 "vite server connection lost"가 남아 있음
- **해결**: 개발 서버 창에서 Ctrl+C 후 `npm run dev` 다시 실행
- **재발 방지**: 화면이 안 열리면 백엔드와 프런트 개발 서버를 둘 다 확인

## 작업 중 안내 오류 (참고)

- 프론트 폴더에 이미 있는데 `cd frontend`를 안내함 → 위치 확인 후 안내하도록 정정
