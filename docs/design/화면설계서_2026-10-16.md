## 1. 화면 구성 기준

포르투나볼 AI의 화면은 일반 사용자 화면과 관리자 화면으로 구분한다.

일반 사용자 화면은 로또 번호 생성, AI 분석, 통계 조회, 당첨 기록, 판매점 지도, 당첨금 계산, 안내 콘텐츠를 이용하는 영역이다.

관리자 화면은 회차 데이터, 발급 기록, 당첨 검증, 익명 인증, 판매점 데이터, AI 사용량, 오류 로그, 스케줄러 상태를 관리하는 운영 영역이다.

모든 화면은 요구사항 명세서 v2의 FE/BE ID와 연결하고, 화면을 바꿀 때는 이 문서의 수정 이력에 기록한다.

## 4. 번호 생성 화면 흐름

임시 확정 토큰 방식(요구사항 BE-36)에 맞춘 사용자 흐름이다.

```
UI-02 게임 수 입력·패턴 선택 → 번호 생성 요청
→ UI-03 결과 표시 (임시 결과, DB 저장 없음)
   ├ 다시 생성: 새 번호를 표시하고 이전 번호는 폐기
   ├ 분석 보기: UI-05로 이동 (임시 결과를 분석)
   └ 발급하기: 확정 → (이미 3회 찬 게임은 해당 게임만 교체) → 발급코드 표시 → DB 저장
→ UI-03 발급 완료 상태 (발급코드, 발급내역 보기)
→ UI-04 발급 내역 조회
```

- 토요일 20:00에 대상 회차가 바뀌면 이전 임시 결과는 발급할 수 없고 재생성을 안내한다.
- 임시 결과가 만료되어도 같은 안내를 보여준다.
- 발급 확정 시 같은 대상 회차에서 같은 조합이 이미 3회 발급된 게임은 해당 게임만 다른 번호로 교체하고, 어느 게임이 바뀌었는지 알린다.
- "다시 생성"을 누르면 바로 번호를 덮어쓰지 않고 게임 수 선택 단계로 돌아간다.

## 5. 고정 안내 문구 배치

모든 화면의 맨 아래 "유의사항" 영역에 한 번만 표시한다. 로또볼이나 카드, AI 응답마다 반복하지 않는다.

| 화면 | 표시 문구 | 위치 |
| --- | --- | --- |
| 모든 사용자 화면 | 통계 기반 생성 번호입니다. 참고만 하세요. 당첨을 보장하지 않습니다. | 화면 맨 아래 유의사항 |
| UI-14 서비스 안내 | 전체 고정 안내문, 상담전화(1336), 19세 미만 구매 불가 | 서비스 안내 상단 |

문구는 글자 크기 12px 이상, 배경 대비 4.5:1 이상의 연한 회색으로 표시하고, 투명도로 숨기거나 스크롤해야만 보이는 위치에 두지 않는다.

## 6. 공통 화면 상태

| 상태 | 화면 처리 방식 |
| --- | --- |
| 로딩 상태 | 데이터 조회 중임을 사용자에게 표시한다. |
| 빈 데이터 상태 | 조회 결과가 없을 경우 안내 문구와 다음 행동 버튼을 제공한다. |
| 오류 상태 | 오류 원인을 쉽게 안내하고 다시 시도 버튼을 제공한다. |
| 권한 없음 | 관리자 화면 접근 시 권한이 없으면 로그인 화면으로 이동한다. |
| 위치 권한 거부 | 지도 화면에서 위치 권한이 거부되면 지역 검색 방식으로 이용할 수 있게 한다. |
| AI 응답 실패 | AI 응답 실패 시 잠시 후 다시 시도 안내와 기본 안내 문구를 표시한다. 번호 생성과 통계는 계속 이용할 수 있다. |
| 임시 결과 만료 | 발급 확정 시 임시 결과가 만료되었으면 새 번호 생성을 안내한다. |
| 번호 교체 알림 | 발급 확정 시 제공 횟수 제한으로 번호가 교체되었으면 바뀐 게임을 표시하고 교체된 번호로 발급 결과를 보여준다. |
| 통계 준비 중 | 회차 통계가 준비 중이면 "준비 중" 상태를 표시하고, 확정된 통계만 기준 회차로 안내한다. |
| 대상 회차 변경 | 번호 생성 중 회차가 바뀌었으면 "대상 회차가 변경되었습니다. 새로운 회차의 번호를 다시 생성해 주세요" 안내를 표시한다. |
| 요청 횟수 초과 | 잠시 후 다시 시도하도록 안내하고 남은 대기 시간을 알린다. |
| AI 한도 초과 | AI 기능은 일시 중단 안내를 표시하고, 번호 생성·통계·조회는 정상 이용할 수 있게 한다. |

## 7. 화면 완료 기준

| 구분 | 완료 기준 |
| --- | --- |
| 일반 사용자 화면 | 메인 메뉴 10개 화면과 패턴 모아보기에 진입할 수 있고, 각 화면의 핵심 기능 흐름이 끊기지 않아야 한다. |
| 관리자 화면 | 관리자 로그인 후 운영 상태, 데이터, 로그, 검수 기능을 확인할 수 있어야 한다. |
| 모바일 화면 | 주요 화면이 작은 스마트폰, 일반·큰 스마트폰, 폴드 외부(좁고 긴 화면)와 내부, 태블릿, PC에서 깨지지 않고 버튼과 텍스트가 겹치지 않아야 한다. |
| 데이터 연결 | 화면에 표시되는 데이터가 백엔드 API 응답 기준으로 정상 출력되어야 한다. |
| 예외 처리 | 데이터 없음, API 실패, 권한 없음, 위치 거부, AI 실패, 임시 결과 만료, 대상 회차 변경, 요청 횟수 초과, AI 한도 초과 상황이 화면에서 안내되어야 한다. |
| 문구 기준 | 모든 화면 맨 아래 유의사항에 고정 안내 문구가 한 번 표시되고 기준(글자 크기, 대비)을 지켜야 한다. |
| 발표 기준 | 번호 생성 → AI 분석 → 통계 조회 → 당첨번호 조회 → 지도 → 관리자 확인 흐름을 시연할 수 있어야 한다. 지도는 3순위이므로 일정에 따라 시연 범위를 조정할 수 있다. |
