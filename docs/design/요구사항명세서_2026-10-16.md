## 포르투나볼 AI 요구사항 명세서

## 1. 프로젝트 개요

### 1.1 프로젝트명

`포르투나볼 AI`

### 1.2 프로젝트 목적

포르투나볼 AI는 로또 번호를 단순 무작위로 제공하는 서비스가 아니라, 역대 로또 데이터를 기반으로 번호 조합, 통계 분석, 회차 정보, 당첨 기록, 판매점 정보를 제공하는 **통계 기반 AI 로또 데이터 서비스**이다.

사용자는 번호 생성, 번호 분석, 꿈풀이 기반 번호 추천, 당첨번호 조회, 당첨금 계산, 로또 명당 정보 등을 한 곳에서 확인할 수 있다.

### 1.3 서비스 방향

- 당첨을 보장하지 않는다.
- 통계 조합은 당첨 확률에 영향을 주지 않는 참고 정보임을 화면에 표시한다.
- 로또 구매를 강요하지 않는다.
- 통계 기반 참고 정보를 재미있고 편리하게 확인할 수 있도록 돕는다.
- 싸구려 운세 사이트가 아니라 고급 데이터 분석 서비스 느낌을 지향한다.

---

## 2. 사용자 유형

### 2.1 일반 사용자

- 회원가입 없이 서비스를 이용한다.
- AI 번호 생성, 번호 분석, 꿈풀이, 회차 조회, 통계 조회 등을 사용할 수 있다.
- 사용자가 발급을 확정한 번호만 게스트 식별값과 발급코드 기준으로 기록된다.

### 2.2 관리자

- 별도 관리자 로그인으로 접근한다.
- 공지, 회차 데이터 재수집, 당첨 인증, 판매점 데이터 등을 관리한다.
- 당첨번호와 당첨금을 직접 입력하거나 수정하지 않고 공식 API 재수집으로만 갱신한다.
- 일반 사용자 화면에는 관리자 로그인 메뉴를 노출하지 않는다.
