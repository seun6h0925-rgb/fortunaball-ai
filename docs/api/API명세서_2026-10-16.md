## 3. 공통 응답 형식

| 구분 | 형식 |
| --- | --- |
| 성공 응답 | `success`, `data`, `message` |
| 실패 응답 | `success`, `errorCode`, `message` |
| 인증 오류 | `401 Unauthorized` (관리자 세션 없음·만료) |
| 권한 오류 | `403 Forbidden` |
| 데이터 없음 | `404 Not Found` |
| 입력값 오류 | `400 Bad Request` |
| 충돌 | `409 Conflict` (대상 회차 변경, 임시 확정 토큰 만료·재사용, 교체할 조합을 만들 수 없는 경우. 같은 조합의 3회 초과는 오류가 아니라 해당 게임을 교체하고 API-04 성공 응답에 교체 정보를 담는다) |
| 요청 횟수 초과 | `429 Too Many Requests` |
| AI 이용 불가 | `503 Service Unavailable` (AI 일일 호출 한도·월 비용 한도 초과, AI 키 없음. 번호 생성·통계는 계속 사용 가능) |
| 게스트 식별값 | 요청 헤더 `X-Guest-Token`으로 전달 |
| 관리자 인증 | 로그인 성공 시 세션 쿠키(HttpOnly)로 인증하고 관리자 API(`/api/admin/**`)는 세션이 없으면 401. 변조 요청 방지(CSRF) 방식은 구현 시 확정 |
| 서버 오류 | `500 Internal Server Error` |
