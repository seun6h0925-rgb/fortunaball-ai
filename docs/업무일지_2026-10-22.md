## 오류·이슈 기록
- 루키 명당이 비어 보임: 화면이 50곳을 요청했으나 서버는 1~10곳만 허용(400) → 10곳으로 맞춤
- 루키 안내 문구가 실제 기준과 달라 오해 소지 → 실제 규칙(최근 12개월, 1등 1회 이상 또는 2등 5회 이상)으로 정정
- `jsqr` 설치 누락으로 Vite 화면이 흰색(import 실패) → `npm install jsqr`
- ESLint 오류(상수 export 위치, 안 쓰는 값) → 별도 파일로 분리, 값 제거
- 수령 가이드 링크가 "계산 기준" 아래에 잘못 놓임 → 세율 출처 줄 삭제, 링크는 수령 가이드 화면으로 이동, 안내 문구 재작성
- 컴퓨터에 파일을 쓸 때 이전 버전이 남는 문제가 반복됨(관리자 회차 데이터가 "준비 중"으로 보임) → 파일 크기를 확인하고 다시 쓰기
- 발급 기록 상세에서 번호 공이 찌그러짐(칸이 좁아 눌림) → 공 크기 고정
- 화면이 계속 "불러오는 중": 프런트 개발 서버(Vite)가 멈춘 것 → `npm run dev` 재시작
