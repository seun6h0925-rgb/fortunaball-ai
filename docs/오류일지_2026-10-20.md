## 1. 용지 QR 당첨 확인 API 번호 불일치

- **발생 위치**: `backend/.../ticket/` (`TicketController`, `TicketCheckRequest`, `TicketCheckResponse`, `TicketCheckService`) 주석, API 명세서
- **증상**: 코드 주석에는 "API-45"로 적혀 있는데, 명세서에서는 이미 API-45가 다른 기능(관리자 로그아웃)의 번호였음
- **원인**: 명세서에 새 번호(API-63)를 정하기 전에 임시 번호를 코드에 적었음
- **해결**: 코드 주석 4곳을 API-63으로 정리(커밋 06dd680)하고, 명세서에 신규 API 63~65 반영(커밋 e99af34)
- **재발 방지**: 새 API는 명세서에서 번호를 먼저 정한 뒤 코드에 적음
