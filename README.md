# 포르투나볼 AI

번호 생성은 AI가 만든 계산식에 통계 데이터를 얹어 로또 정보·번호 생성하는 서비스입니다. 

> 모든 결과는 당첨을 보장하지 않는 참고 정보입니다.

## 주요 기능

- 통계 기반 번호 생성
- AI 로또 애널리스트
- AI 꿈풀이
- 회차별 당첨번호 조회
- 로또 통계 분석
- 발급코드 및 발급 내역 조회
- 당첨 결과 검증
- 로또 명당·판매점 지도
- 당첨금·세금 계산
- 관리자 페이지

## 기술 스택

- Java 21
- Spring Boot 3.x
- Spring Data JPA
- MySQL 8.0
- React
- JavaScript
- Fetch API

## 폴더 구조

```text
fortunaball-ai/
├─ backend/          Spring Boot 백엔드
├─ frontend/         React 프론트엔드
├─ docs/
│  ├─ db/            DB 설계서·SQL
│  ├─ api/           API 명세서
│  ├─ design/        목업·화면 설계
│  └─ requirements/  요구사항·기능 명세서
└─ .env.example      환경변수 예시
```

## 데이터 처리 원칙

- 회차와 당첨번호는 공식 데이터만 사용합니다.
- 공식 데이터는 중복 검증 후 저장합니다.
- 스케줄러 실행 결과와 오류를 로그로 관리합니다.
- 번호 생성 결과는 발급 확정 시에만 DB에 저장합니다.
- 꿈 데이터는 출처를 확인한 참고 자료로 관리합니다.

## 개발 원칙

- 백엔드를 먼저 구현한 뒤 프론트를 연결합니다.
- 기능 하나씩 구현하고 테스트합니다.
- 기존 설계와 용어를 임의로 변경하지 않습니다.
- API 키와 비밀번호를 코드에 작성하지 않습니다.
- 관리자 기능은 별도 권한으로 보호합니다.
