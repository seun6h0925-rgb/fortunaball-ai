# 포르투나볼 AI

통계 기반 로또 정보·번호 생성 서비스. 번호는 서버의 통계 알고리즘만 만들고, AI는 설명만 한다.

## 구성
- AI 애널리스트, AI 꿈풀이, 통계 분석, 회차별 당첨번호, 우리 서비스 당첨 기록, 명당 지도, 세금 계산기, 관리자 사이트

## 기술
- Java 21, Spring Boot 3.x, MySQL 8.0, React(fetch)

## 폴더
| 폴더 | 내용 |
| --- | --- |
| `backend/` | Spring Boot 서버 (패키지 `com.fortunaball`) |
| `frontend/` | React 화면 |
| `docs/db/` | DB 설계서, `schema.sql` |
| `docs/design/` | 목업, 디자인 기준 |
| `docs/api/` | API 명세 |

## 시작하기
1. `.env.example` 을 복사해 `.env` 를 만들고 값을 채운다. (`.env` 는 커밋하지 않는다)
2. MySQL 8.0 에서 `docs/db/schema.sql` 을 실행한다.
3. 백엔드 → 프론트 순서로 실행한다. (세부 방법은 개발하면서 채운다)

## 작업 원칙
- 백엔드를 먼저, 프론트는 그다음. 한 번에 기능 하나씩 끝낸다.
- 중요하거나 헷갈리는 코드는 위에 주석으로 이유를 적는다.
- 비밀값은 `.env` 에만 둔다. 코드와 문서에 쓰지 않는다.
- 회차·당첨번호는 더미로 만들지 않고 공식 데이터로만 적재한다.
